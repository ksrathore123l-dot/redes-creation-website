A premium responsive HTML/CSS/JavaScript recreation based on the supplied visual reference and Redes Creation's publicly listed service profile.

- `css/style.css` — all layout, responsive styling and animations
- `js/script.js` — navigation, service modal, slider, counters and scroll effects
- `assets/` — locally bundled reference crops from the supplied screenshot

## Run
Open `index.html` directly in a modern browser.

The Google Fonts import is optional; the site falls back to system fonts if offline.
